# NAW VISUALFORGE

**Create. Edit. Elevate.**

A responsive, static storefront for NAW VISUALFORGE, built with plain HTML, CSS and JavaScript.

## Website files
- `index.html` — page content and SEO description
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Open this repository's **Settings** tab.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**.
5. Click **Save** and wait for GitHub Pages to publish.

Expected website address:
https://baldevsingh1980k-byte.github.io/naw.visualforge/
